# Desk-organizer
<img width="722" height="545" alt="image" src="https://github.com/user-attachments/assets/5d8d6292-ef43-4e6c-857b-2016cf2d41aa" />

This project is a Desk organizer. Its dimensions are 21 x 14 x 10.5. It has a lot of different utilities built into it. It has 3 drawers, a big one and 2 small ones, a pencil holder/compartment that you can use for pencil or other small things, and a coin bank, where u can drop a coin in from the top and it deposits into a small chamber at the bottom that can be opened by a small door.

Assembly: The project has 3 main parts to it that will have to be printed separately: the drawers, the main compartment and the front cover. The drawers are built with a rail mechanism that makes them detachable, and for the front cover, the thicker area around the coin bank door fits perfectly into the compartment (with tolerance obviously), so I can just use some glue to stick the front on.
